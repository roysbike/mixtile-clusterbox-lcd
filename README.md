# Панель Mixtile ClusterBox

Прошивка для экрана ESP32-32E (модуль E32R28T, 320×240, резистивный тач). Панель стоит на ClusterBox и показывает состояние BMC и четырёх нод Talos без входа в LuCI.

Сверху — uplink **WAN** и сеть нод **LAN**. На этой плате LAN — это фабрика MIOP (`omi0`, адреса `10.20.0.0/24`), а не мост OpenWrt `br-lan`. Ниже сетка 2×2: имя слота, `OS: talos`, состояние `Ready` / `NotReady` / `Pending`, IP ноды и условие PCIe. Пока связь с BMC есть, по верхней кромке бежит полоска, а точка у живой ноды пульсирует.

Данные берутся с BMC по ubus: `nodectl status`, плата, прошивка и адреса интерфейсов. Нужна прошивка контроллера с `nodectl` из ветки [`feature/nodectl-ui`](https://github.com/roysbike/mixtile-clusterbox-mt7620a-openwrt/tree/feature/nodectl-ui).

Wi-Fi панели задаётся на самом экране: если сети ещё нет, она поднимает открытую точку `ClusterBox-LCD`, страница настройки — `http://192.168.4.1`. Удержание верхней полосы около трёх секунд открывает настройку снова. Логин BMC попадает в прошивку только на сборке, из локального `.env`.

## Сборка

Нужен [PlatformIO](https://platformio.org/).

```bash
cp .env.example .env
# заполните CLUSTER_HOST, CLUSTER_USER, CLUSTER_PASSWORD
pio run -t upload
```

`WIFI_SSID` и `WIFI_PASSWORD` можно оставить пустыми: тогда сеть выбирается с телефона. Если их заполнить, панель использует их только до первой сохранённой сети.

Порт USB определяется сам. Скорость загрузки `115200`: чип CH340 на этой плате обрывает запись на `921600`.

При первом включении и после смены ориентации тач просит нажать четыре креста. Если картинка перевёрнута, в `include/config.h` поставьте `kPanelRotation` в `3`.

## Ветка

`integration` — прошивка панели для встройки в ClusterBox. Секреты в репозиторий не входят: `.env` и `include/secrets.h` перечислены в `.gitignore`.
